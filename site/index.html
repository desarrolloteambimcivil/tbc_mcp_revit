How it worksCómo funciona

Two small programs on your machine. Your agent talks MCP to a local server; the server talks to an add-in inside Revit, which runs each request on Revit's own thread. Dos programas pequeños en tu equipo. Tu agente habla MCP con un servidor local, y el servidor con un complemento dentro de Revit, que ejecuta cada petición en el hilo de Revit.

Local by defaultLocal por defecto

Loopback or a named pipe with a per-session token. Your model never goes to a server of ours.Conexión local o pipe con token por sesión. Tu modelo nunca pasa por un servidor nuestro.

Every change on recordCada cambio registrado

Changed elements are reported with each call, and History → Issues in the ribbon keeps warnings and decisions.Cada llamada informa de los elementos cambiados, y Historial → Incidencias en la cinta guarda avisos y decisiones.

Read-only when you wantSolo lectura si quieres

Start with --read-only or limit the toolsets, and the agent can only look, not touch.Arranca con --read-only o limita los grupos de herramientas, y el agente solo podrá mirar.
